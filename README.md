# 눈길

눈과 목소리로 웹을 쓰는 크롬 확장 프로그램이에요. 마우스를 쓰기 어려운 사람을 위해 만들었어요.

항목을 바라보면 표시되고, 계속 바라보거나 "클릭"이라고 말하면 눌려요. 특별한 장비 없이 웹캠과 마이크만 있으면 돼요.

## 설치

1. `chrome://extensions`를 열고 **개발자 모드**를 켜요.
2. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `extension` 폴더를 골라요.
3. 안내 화면이 바로 열려요. 카메라와 마이크를 허용해요. macOS에서 물으면 시스템 설정에서도 크롬을 허용해요.
4. 안내에 따라 점을 바라봐요. 1분쯤 걸려요. 끝나면 사용법 안내가 이어져요. 설정창의 **사용법 보기**로 다시 볼 수 있어요.

## 응시 클릭

바라보는 항목에 테두리가 표시돼요. 움직이는 포인터는 없어요. 기본은 "클릭"이라고 말해서 누르는 거예요. 팝업에서 **응시 클릭**을 켜면 바라보기만 해도 눌려요. 0.5초 뒤 카운트다운이 시작되고, 1.5초가 지나면 눌려요.

결제나 삭제처럼 보이는 버튼은 응시로 눌리지 않아요. 빨간 테두리가 뜨면 "클릭"이라고 말해 확인해요.

메뉴처럼 항목이 붙어 있어서 옆 항목이 잡히면 고개를 까딱해 옮기거나, "번호"로 고르세요.

말하는 동안에는 시선 입력이 잠시 멈추고 하이라이트가 그대로 있어요. 그래서 "클릭"이라고 말하면 말하기 전에 보던 항목이 눌려요. AI 기능이 동작 중일 때는 멈추지 않아요.

## 고개 까딱

표시된 항목이 원하는 것이 아니면, 원하는 쪽으로 고개를 빠르게 까딱하고 돌아오세요. 그 방향의 옆 항목으로 넘어가요. 왼쪽, 오른쪽, 위, 아래를 지원해요.

천천히 돌리거나 돌린 채로 있으면 평소 움직임으로 보고 무시해요. 대각선도 무시해요. 팝업에서 끌 수 있어요.

## 음성 명령

| 말하기 | 동작 |
| --- | --- |
| 클릭 | 바라보는 항목 누르기 |
| 번호, 이어서 3번 | 번호를 붙여서 고르기 |
| 클릭 5 | 번호가 붙은 항목 바로 고르기 |
| 아래로 / 위로 | 스크롤 |
| 맨 위로 / 맨 아래로 | 끝으로 이동 |
| 뒤로 / 앞으로 | 페이지 이동 |
| 새로고침 | 페이지 다시 읽기 |
| 입력 안녕하세요 | 선택한 칸에 글자 입력 |
| 눈길 켜줘 / 눈길 꺼줘 | 말로 켜고 끄기 |
| 교정 / 시선 맞춤 | 어긋난 시선을 2초 만에 맞추기 |
| 빠른 교정 | 점 4개로 6초 만에 다시 맞추기 |
| 읽어줘 / 단순 보기 | 본문 읽어 주기, 본문만 보기 |
| 멈춰 / 다시 시작 | 일시정지와 재개 |
| 취소 | AI 작업, 번호, 도움말 닫기 |
| 도움말 | 명령어 목록 보기 |

## 다른 조작 방법

팝업에서 각각 켜고 끌 수 있어요.

| 방법 | 동작 | 기본값 |
| --- | --- | --- |
| 입 벌리기 (0.9초) | 아래로 스크롤, 벌리고 있으면 계속 | 켜짐 |
| 팝 소리 / 허밍 | 클릭 / 아래로 스크롤 | 꺼짐, 켜면 음성 명령이 꺼져요 |

**머리 보조**를 켜면 머리의 좌우 방향을 시선 계산에 함께 넣어요. 좌우로 자세가 달라져도 시선이 덜 어긋나고, 머리를 그쪽으로 조금 돌려 미세 조정할 수 있어요. 빠르게 까딱하는 순간에는 시선 입력을 잠시 멈춰요. 그래서 교정할 때는 머리를 움직이지 말고 눈으로만 점을 봐 주세요.

다시 켜거나 크롬을 1분 넘게 떠났다 돌아오면 **빠른 교정**(점 4개, 약 6초)이, 크롬을 잠깐 떠났거나 카메라에서 2초 넘게 벗어났다가 돌아오면 2초 시선 맞춤이 자동으로 시작돼요. 끝날 때까지 시선 클릭은 동작하지 않아요. "빠른 교정"이라고 말하거나 설정창 버튼으로도 실행할 수 있어요.

어긋나면 "교정"이나 "시선 맞춤"이라고 말하거나 팝업 버튼을 누르고 가운데 점을 2초 보세요. 앉은 자리나 자세, 조명이 바뀌면 다시 교정하세요.

## AI 기능

팝업에서 ChatGPT에 로그인하면 쓸 수 있어요. 내 ChatGPT 계정을 쓰고, API 키는 필요 없어요.

| 말하기 | 동작 |
| --- | --- |
| 뉴스 클릭, 로그인 버튼 눌러줘 | 그 이름의 버튼이 있으면 AI 없이 바로 눌러요. 화면 밖이면 스크롤해서 찾아가요 |
| 헤이 눈길, 로그인 버튼 눌러줘 | 화면에서 찾아 누르기. 중요하거나 애매한 항목은 번호로 확인 |
| 헤이 눈길, 뉴스 찾아줘 | 맞는 항목에 번호만 표시 |
| 단순 보기 | 본문을 바로 보여 주고, 쉬운 말로 바꿔서 교체 |
| 요약해줘 | 짧게 요약해서 보여 주고 읽어 주기 |
| 헤이 눈길, 지메일 들어가서 메일 작성해줘 | 페이지 이동, 누르기, 입력을 반복해서 끝까지 수행 (최대 12단계) |

AI가 작업하는 동안 "취소"나 "멈춰"라고 말하면 멈춰요. 전송, 결제, 삭제처럼 되돌리기 어려운 버튼은 누르기 전에 멈추고, "1번"이라고 말해야 눌려요. 비밀번호와 결제 칸에는 입력하지 않고, 로그인은 직접 해야 해요. 웹페이지 글이 AI를 속이려 할 수 있어서, 이 안전장치는 AI가 아니라 확장 프로그램 코드에 들어 있어요.

기본 명령이 아닌 말은 모두 AI가 처리해요. "헤이 눈길"이라고 먼저 불러도 되고, 이름만 부른 뒤 8초 안에 말해도 돼요. **마이크에 들어온 주변 사람의 말도 AI로 전송되고 그대로 실행될 수 있으니**, 주변에 다른 목소리가 있으면 팝업에서 **AI 자동 수행**을 꺼 두세요. AI 작업 중에 들린 다른 말은 새 작업을 시작하지 않아요.

이 기능은 OpenAI Codex CLI의 OAuth 클라이언트로 로그인하고, 그 클라이언트가 쓰는 주소를 호출해요. OpenAI가 자사 도구용으로 둔 경로라 약관상 회색 지대이고, 언제든 멈출 수 있어요. 해커톤 데모에는 쓸 수 있지만, 공개 출시나 크롬 웹 스토어 등록 전에는 공식 API로 바꿔야 해요.

## 개인정보

- **카메라:** MediaPipe로 기기 안에서만 처리해요. 영상을 저장하거나 보내지 않아요. 크롬에서 다른 앱으로 나가면 3초 뒤 카메라와 마이크가 꺼지고, 돌아오면 다시 켜져요.
- **음성:** 크롬 음성 인식을 써서 음성이 Google로 전송될 수 있어요. "눈길 꺼줘"로 끄면 카메라는 꺼지지만, "눈길 켜줘"를 듣기 위해 마이크는 켜져 있어요. 마이크까지 끄려면 팝업 스위치를 쓰세요. 소리 조작 모드는 기기 안에서만 처리해요.
- **AI 기능:** 로그인 전에는 꺼져 있어요. 로그인 후에는 기본 명령이 아닌 말과 페이지 본문이나 화면의 항목 이름, 페이지 주소(쿼리 문자열 제외)가 내 ChatGPT 계정으로 전송돼요. 메일함에서는 항목 이름에 메일 제목이 포함돼요. 로그인한 상태에서 "단순 보기"를 말하면 본문이 자동으로 전송돼요. 입력 칸에 쓴 내용은 보내지 않아요. 로그인 토큰은 확장 프로그램 저장소에 암호화 없이 저장돼요.
- **진단 기록:** 문제를 찾기 위해 프레임 수, 커서 좌표, 명령 이름 같은 숫자를 기기 안에만 저장해요. 페이지 주소와 말한 내용은 기록하지 않아요.

## 알려진 한계

- 웹캠 시선은 정확하지 않아요. 조명이 밝고 머리가 안정적일수록 좋아요.
- 맨 위 프레임만 조작할 수 있어서, 다른 사이트의 iframe 안은 누를 수 없어요.
- `chrome://` 페이지와 크롬 웹 스토어에서는 동작하지 않아요.
- 스크립트 클릭을 무시하는 사이트가 있어요.
- 교정은 페이지 확대율 100%를 기준으로 해요.

## 개발

```sh
(cd extension && zip -qr ../landing/nungil-extension.zip . -x '.*')  # 랜딩 페이지 다운로드 파일 만들기
npm install
npm test          # 시선 모델, 명령 해석, 로그인 로직
npm run e2e       # 실제 확장 프로그램을 Chromium에서 시험 (사진을 가짜 웹캠으로 사용)
```

브라우저 테스트는 실제 MediaPipe를 돌리지만 시선 값, 음성 명령, AI 응답은 흉내 낸 값을 넣어요. 실제 눈 움직임, 실제 음성, 실제 OpenAI 응답은 시험하지 않아요.
