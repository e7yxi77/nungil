눈길은 여기 있어요

크롬 오른쪽 위의 퍼즐 조각 아이콘을 눌러 찾을 수 있어요.

  1. 주소창 오른쪽의 퍼즐 조각을 눌러요.
  2. 눈길 옆의 핀을 눌러 고정해요. 툴바에 아이콘이 항상 보여요.
  3. 아이콘을 누르면 설정창이 열려요.

바라보면 눌려요

누르고 싶은 항목을 바라보면 파란 테두리가 생겨요. 0.5초 뒤 동그란 카운트다운이 시작되고, 1.5초가 지나면 눌려요.

옆 항목이 잡히면고개를 까딱해 옮겨요. "번호"로 골라도 돼요
결제나 삭제 버튼이면빨간 테두리가 떠요. "클릭"이라고 말해 확인해요

시선이 어긋나면

자세가 바뀌면 조금씩 어긋날 수 있어요. 바로 고칠 수 있어요.

"시선 맞춤"가운데 점을 2초 보면 끝. 설정창 버튼도 같아요
시선 교정자리나 조명이 크게 바뀌면 설정창에서 다시 해요

말로 조작해요

말하는 동안에는 시선이 잠시 멈춰요. "클릭"이라고 하면 말하기 전에 보던 항목이 눌려요. "도움말"로 전체 목록을 볼 수 있어요.

"클릭"바라보는 항목 누르기
"번호", "3번"번호를 붙여서 고르기
"아래로", "위로", "뒤로"스크롤과 페이지 이동
"입력 안녕하세요"글자 입력
"읽어줘", "단순 보기"본문 읽어 주기, 본문만 보기
"멈춰", "다시 시작"일시정지와 재개

AI에게 맡겨 보세요

설정창에서 ChatGPT 로그인을 하면, 말한 일을 AI가 대신해요.

"지메일 들어가서 메일 작성해줘"끝까지 알아서 수행
"로그인 버튼 눌러줘"화면에서 찾아 누르기
"요약해줘"짧게 요약해 읽어 주기
"취소"AI 작업 바로 멈추기

전송, 결제, 삭제는 AI가 혼자 누르지 않고 먼저 물어봐요. 비밀번호도 직접 입력해요. AI를 쓸 때는 페이지 내용과 말한 요청이 내 ChatGPT 계정으로 전송돼요.
