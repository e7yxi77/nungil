움직임만으로 조작하세요.

움직이는 포인터는 없어요. 웹캠이 시선을 따라가고, 바라보는 항목에 파란 테두리가 표시돼요.

  1. 바라보면 항목이 표시돼요
  2. 고개를 까딱하면 옆 항목으로 넘어가요
  3. 1.5초 더 바라보면 눌려요

목소리

브라우저를 제어하세요.

누르고 싶은 것을 말하면, AI가 화면에서 항목을 찾아 눌러요.

  • "검색 버튼 클릭해 줘."
  • "다음 페이지로 이동해 줘."
  • "새 탭 열어 줘."

AI 스마트 자동화 · Codex

원하는 것을 말하세요.
AI가 실행합니다.

"Google에서 해커톤을 검색해 줘." 한마디면 AI가 단계를 나누고, 브라우저에서 차례로 수행해요.

  1. Google 검색 페이지 접속
  2. 검색창 인식
  3. '해커톤' 입력
  4. 검색 실행
  5. 검색 결과 표시
  • "유튜브에서 인공지능 관련 영상을 찾아줘."
  • "이 페이지의 핵심 내용을 요약해 줘."
  • "현재 페이지에서 다음 단계로 진행해 줘."

전송, 결제, 삭제는 AI가 혼자 누르지 않아요. 먼저 멈추고 물어봐요.
